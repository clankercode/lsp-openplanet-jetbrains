# Diagnostics demo

Original minimal example authored for this repository, under the repository's dual license. It uses Openplanet's conventional `void Main()` entry point and `info.toml` metadata. The incorrect assignment and missing helper are deliberate test inputs, not a runnable game plugin. No game, third-party plugin source, or type database is copied. Open this directory as a project and inspect `Main.as` using the actual openplanet-lsp server.
